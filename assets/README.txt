ASSETS DIRECTORY
================

Place your application assets here.

Required files (when available):
  - icon.ico       : Application icon (for .exe)
  - logo.jpg       : Logo used in the About dialog (e.g. 400x200)
  - thumbnail.jpg  : Thumbnail for store/installer listing (e.g. 1280x720)

Build references:
  - live_translate.spec  → icon.ico
  - installer/setup.iss  → icon.ico, logo.jpg, thumbnail.jpg
